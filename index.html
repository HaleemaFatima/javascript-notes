01

Variables

A variable is a named box that holds a value. You make one, then reuse it.

let, const, var

  • let — value can change later. Use this most of the time.
  • const — value is fixed once set. Use when it shouldn't change.
  • var — old style. Avoid it; mention it only if your exam asks.
let age = 20;          // can change
const name = "Sara";   // fixed
age = 21;               // OK
// name = "Ali";       // ERROR: const can't be reassigned
Exam tip: a variable name can't start with a number and can't have spaces. userName is fine, 2user is not.
02

Data Types

JavaScript values come in a few flavours. Knowing the type tells you what you can do with it.

The main types

  • Number — 42, 3.14
  • String — text in quotes, "hi"
  • Boolean — true or false
  • Undefined — declared but no value yet
  • Null — intentionally empty
  • Object / Array — collections (later sections)

Check a type with typeof

typeof 42        // "number"
typeof "hi"      // "string"
typeof true      // "boolean"
typeof undefined // "undefined"

03

Operators

Operators do work on values: maths, comparisons, and combining conditions.

Maths & assignment

5 + 2   // 7
5 - 2   // 3
5 * 2   // 10
5 / 2   // 2.5
5 % 2   // 1  (remainder)
x += 1  // same as x = x + 1

Comparison & logic

5 === 5   // true  (equal value & type)
5 == "5"  // true  (loose — avoid)
5 !== 3   // true  (not equal)
5 > 3     // true
a && b      // AND — both true
a || b      // OR — at least one
!a          // NOT — flips it
Remember: use === not ==. The triple checks type too, which avoids surprises.
04

Conditions

Run different code depending on whether something is true.

if / else if / else

let marks = 75;

if (marks >= 80) {
  console.log("A grade");
} else if (marks >= 60) {
  console.log("B grade");   // this runs
} else {
  console.log("Keep going");
}
Shortcut (ternary): let pass = marks >= 50 ? "yes" : "no";

05

Loops

Repeat a block of code without copy-pasting it. The exam favourite.

for loop

for (let i = 1; i <= 5; i++) {
  console.log(i);
}
// prints 1 2 3 4 5

Three parts: start, condition, step.

while loop

let n = 3;
while (n > 0) {
  console.log(n);
  n--;
}
// prints 3 2 1
Watch out: always change the variable inside, or the loop runs forever.

06

Functions

A reusable block you can call by name. Give it inputs, get an output back.

Declaring and calling

function add(a, b) {
  return a + b;
}

let total = add(3, 4);  // 7

// arrow function — same thing, shorter
const square = (x) => x * x;
square(5);  // 25
  • Parameters — the inputs in the brackets (a, b).
  • return — sends a value back. Without it, the function returns undefined.
Exam tip: defining a function does nothing on its own. You must call it with add(3, 4) to run it.
07

Arrays

An ordered list of values. Counting starts at 0, not 1.

Basics

let fruits = ["apple", "mango", "kiwi"];

fruits[0]        // "apple"
fruits.length    // 3
fruits.push("fig") // add to end
fruits.pop()       // remove last

Looping an array

for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

// or the cleaner forEach
fruits.forEach(f => console.log(f));
Index trap: the last item is arr[arr.length - 1], never arr[arr.length].
08

Objects

Group related data with named keys instead of numbered slots.

Key–value pairs

let student = {
  name: "Ahmed",
  age: 20,
  passed: true
};

student.name       // "Ahmed"  (dot notation)
student["age"]    // 20      (bracket notation)
student.age = 21;  // update a value
student.city = "Lahore"; // add a new key
Array vs Object: use an array for a list of similar things, an object for one thing with named properties.
09

DOM Basics

The DOM lets JavaScript read and change the web page. Common in lab tasks.

Select & change

// grab an element by its id
let box = document.getElementById("box");

// change its text
box.textContent = "Hello!";

// change its style
box.style.color = "red";

Respond to a click

let btn = document.getElementById("btn");

btn.addEventListener("click", () => {
  alert("Button clicked!");
});

React

A library for building UI out of reusable components. Instead of poking the DOM by hand, you describe what the screen should look like and React updates it for you.

A component is a function that returns JSX

JSX looks like HTML but lives inside JavaScript. A component's name must start with a Capital letter.

function Welcome() {
  return <h1>Hello, lab!</h1>;
}

// use it like a tag:
<Welcome />
JSX rule: a component must return one top-level element. Wrap siblings in a <div> or an empty <>...</> fragment.

Props — passing data in

Props are inputs to a component, like function arguments.

function Greet(props) {
  return <p>Hi {props.name}</p>;
}

// pass it in:
<Greet name="Sara" />

Curly braces { } drop JavaScript into JSX.

State — data that changes

useState gives a component memory. Changing state re-renders the screen.

import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);
  return (
    <button onClick={() => setCount(count + 1)}>
      Clicked {count} times
    </button>
  );
}
Never change state directly (count++). Always use the setter (setCount) so React knows to re-render.

Rendering a list

Use .map() to turn an array into elements. Each item needs a unique key.

const fruits = ["apple", "mango", "kiwi"];

<ul>
  {fruits.map((f, i) => (
    <li key={i}>{f}</li>
  ))}
</ul>

Three.js

A library for drawing 3D graphics in the browser using WebGL. Three things always go together: a scene, a camera, and a renderer.

The three core pieces

  • Scene — the world that holds your objects.
  • Camera — your point of view into the scene.
  • Renderer — draws the scene onto a <canvas>.
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, w/h, 0.1, 1000);
const renderer = new THREE.WebGLRenderer();
renderer.setSize(w, h);
document.body.appendChild(renderer.domElement);

Geometry + Material = Mesh

A shape (geometry) plus a surface look (material) makes a mesh you add to the scene.

const geo = new THREE.BoxGeometry(1, 1, 1);
const mat = new THREE.MeshStandardMaterial(
  { color: 0x9d4edd }
);
const cube = new THREE.Mesh(geo, mat);
scene.add(cube);
camera.position.z = 3;

The animation loop

To make things move, redraw every frame with requestAnimationFrame.

function animate() {
  requestAnimationFrame(animate);
  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;
  renderer.render(scene, camera);
}
animate();
Dark canvas? A MeshStandardMaterial needs a light. Add new THREE.DirectionalLight() to the scene or use MeshBasicMaterial which ignores light.
